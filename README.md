# Team guinnessssss: poker bot submission

Members: Artemijs, Roman, Andrii.

The submission is the 5 files in this folder:

- `guinnessssss.pkl`: the pickled `Model()`, built with
  `python -m submit --team guinnessssss`.
- `model.py`, `pbbrain.py`, `pbcore.py`, `pbpre.py`: the code it was
  built from.

Put them in the root of the organisers' `poker_bot` repo, next to
`card_utils.py` and the other engine files.
